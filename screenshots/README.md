## Redaction Checklist

Before adding screenshots, blur or remove:

- API keys, tokens, passwords, app secrets, webhook URLs
- Feishu appId, appSecret, verification token, encrypt key
- Dify API keys, admin account, internal endpoint, workflow secrets
- OpenClaw local config paths that expose private usernames or credentials
- Personal accounts, emails, phone numbers, avatars if necessary
- Enterprise names, customer names, real incident records, real chat logs
- Internal URLs, private IP addresses, server names, database names

Only add screenshots that are safe for a public GitHub repository.
