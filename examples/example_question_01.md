# Example Question 01

```text
进入地下井进行有限空间检查作业前，需要做哪些准备？
```

## Scenario

The user is asking about preparation before entering an underground well for confined space inspection work.

## Expected Answer Dimensions

- 作业许可或现场确认
- 风险识别
- 通风与气体检测
- PPE
- 外部监护人
- 应急准备
- 作业前检查清单
- 隐患整改建议
- Safety disclaimer
