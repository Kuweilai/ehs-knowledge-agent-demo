# Example Answer 01

> Demo answer based on simulated EHS knowledge base content. This is not legal advice or a replacement for site EHS approval.

## 1. 简短结论

进入地下井进行有限空间检查前，不能只凭经验判断安全状态。应先确认空间性质、作业目的、进入人数、通风和气体环境，并落实外部监护、通讯和应急准备。若气体检测异常、通风不足、无监护或应急措施不明确，不应进入。

## 2. 主要风险

- 缺氧、中毒、窒息
- 可燃气体导致火灾或爆炸
- 地下井内滑倒、坠落、被困
- 通讯中断或撤离通道受阻
- 盲目施救导致二次伤害

## 3. 作业许可与现场确认

- 明确进入目的、检查范围、作业时长和进入人数
- 确认地下井历史用途、可能残留物和已知危险因素
- 明确现场负责人、进入人员、外部监护人和应急联络方式
- 按现场制度完成有限空间作业审批或确认流程

## 4. 通风与气体检测

- 进入前应进行气体检测或风险确认，重点关注氧含量、有毒有害气体和可燃气体
- 检测结果异常或无法确认安全状态时，不得进入
- 必要时采取持续通风措施
- 作业时间较长、内部残留物被扰动或条件变化时，应警惕环境重新恶化

## 5. PPE 与工具

- 根据风险配置安全帽、防滑鞋、手套、眼面部防护、呼吸防护等 PPE
- 如存在缺氧、中毒、飞溅、触电等风险，应按现场要求配置专项防护装备
- 照明、用电工具和通讯设备应满足现场安全条件，避免形成新的电气风险或点火源

## 6. 监护人与应急准备

- 设置外部监护人，监护人不得擅离岗位
- 进入人员与监护人之间应保持有效联络
- 现场应提前明确报警、撤离、救援和上报流程
- 救援必须以自身安全为前提，严禁无防护盲目入内救人

## 7. 作业前检查清单

- [ ] 已确认地下井属于有限空间管理范围
- [ ] 已明确作业目的、时长、人数和负责人
- [ ] 已完成现场审批或作业确认
- [ ] 已识别缺氧、中毒、可燃气体、滑倒、坠落和被困风险
- [ ] 已完成气体检测或风险确认
- [ ] 已准备必要通风措施
- [ ] 已确认照明、通讯和撤离通道
- [ ] 已配置合适 PPE 和工具
- [ ] 已设置外部监护人
- [ ] 已确认应急联络和救援准备

## 8. 隐患整改建议

如果发现气体环境不明、井口周边障碍物影响撤离、通风不足、无监护人、通讯不可靠或 PPE 不匹配，应先停止进入计划，完成整改和复查后再重新评估。不能用“以前进去过没事”替代检测、确认和审批。

## 9. Safety Disclaimer

以上内容仅基于模拟知识库生成，用于 AI Agent Demo 展示。有限空间属于高风险作业，实际作业必须遵守当地法律法规、企业正式制度和现场许可要求，并由专业 EHS 人员审核。
