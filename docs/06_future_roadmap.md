# Future Roadmap

## More EHS Scenarios

扩展更多场景，例如叉车作业、吊装作业、设备维修、上锁挂牌、承包商管理、消防巡检和环境合规。

## Better RAG Citation Quality

改进知识库检索和引用质量，让 Agent 能明确说明答案来自哪个知识库条目、哪个章节，并降低无依据补充。

## Structured Checklist Generation

把作业前检查清单设计成更稳定的结构化输出，例如 JSON、表格或可导出的表单。

## Automated Regulation Collection

探索法规、标准和企业制度的自动收集、版本管理和人工审核流程。公开 Demo 阶段不自动引用法律条文，避免编造或过期内容。

## Token Usage Evaluation

记录不同模型、不同知识库规模和不同 Prompt 下的 token usage、响应速度和回答质量。

## Model Comparison

对比不同模型在 EHS 问答、风险识别、结构化输出和中文安全表达上的差异。

## Feishu / Enterprise IM Refinement

完善企业聊天入口体验，例如多轮追问、图片隐患识别、消息卡片、审批链接和人工 EHS 转接。

## Knowledge Base Maintenance Workflow

建立知识库更新、审核、发布和回滚流程，确保 AI Agent 使用的是经过确认的安全资料。
