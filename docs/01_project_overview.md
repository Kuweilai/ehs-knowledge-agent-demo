# Project Overview

## 项目背景

EHS Knowledge Agent Demo 是一个面向企业安全管理场景的 AI Agent 展示项目。它来自一组本地模拟 Demo 的整理版本，目标是展示 AI Agent 如何辅助 EHS 知识问答、风险识别、作业前检查和隐患整改建议。

本仓库只保留公开展示所需的说明、Prompt、模拟知识库、示例问答和脱敏配置示例，不包含任何真实部署环境或私有数据。

## 为什么 EHS 适合 AI Agent

EHS 工作中存在大量重复但重要的知识查询和结构化判断，例如：

- 某类作业开始前需要确认哪些条件
- 某个隐患可能带来什么风险
- 现场应优先采取哪些整改措施
- 新员工需要了解哪些基本安全规则
- 作业人员应该佩戴哪些 PPE

这些问题既需要知识库支撑，也需要按安全管理逻辑进行结构化回答。因此，RAG Knowledge Base 与 Agent prompt 的组合适合用来做一个可解释、可约束、可演示的 EHS 助手。

## 核心能力

- 基于模拟 EHS 知识库回答问题
- 对有限空间、动火、高处作业、临时用电、化学品等场景进行风险提示
- 生成作业前检查清单
- 给出隐患整改建议和复查要点
- 在回答中明确不确定性和安全边界
- 通过 Feishu Bot 或 Web Chat 作为企业用户入口

## 当前状态

当前仓库是 public showcase version。它用于说明 Demo 设计、知识库结构、Prompt 方案和集成思路。它不是可直接连接真实生产系统的部署包。

## Demo 目的

本项目可用于：

- 展示 AI Agent 在 EHS 管理场景中的应用价值
- 对比 OpenClaw 与 Dify 两条实现路径
- 作为 AI model / token application 的公开项目链接
- 作为后续扩展真实 RAG、企业 IM 集成和安全工作流的基础说明
