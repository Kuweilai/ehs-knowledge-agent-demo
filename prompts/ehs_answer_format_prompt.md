# EHS Answer Format Prompt

When answering an EHS question, use the following structure when applicable:

## 1. 简短结论

Summarize the main safety point in 1-3 sentences.

## 2. 主要风险

List the most relevant risks based on the knowledge base.

## 3. 作业前准备

Describe required preparation such as work scope confirmation, authorization, site checks, isolation, ventilation, equipment, PPE, and emergency readiness.

## 4. 检查清单

Provide a checklist that users can review before work begins.

## 5. 禁止事项

List behaviors that should not happen in the scenario.

## 6. 隐患整改建议

If the question includes a hazard, suggest practical rectification measures and follow-up checks.

## 7. 不确定性与安全声明

State any uncertainty. Remind the user that high-risk work must follow official site procedures and be reviewed by qualified EHS professionals.
